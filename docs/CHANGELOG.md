# 更新记录

## v1.1.0 · 2026-11-14

**手感与画面**

- 火球改成**长按 E 蓄力**：手持火球随蓄力放大，松开投出，体积最大 **5 倍**，伤害与爆炸半径同步放大
- 投掷动作 0.14 秒：手臂前甩、震屏 `0.18 + 蓄力×0.26`、手部灯爆闪、低频音效随蓄力变沉
- 死亡时**先结束这一局再弹 GAME OVER**（此前会先复活导致卡片闪没）

**性能**

- 粒子改成 **260 个预分配对象池**：一次 20 连爆 160 颗火花，场景节点增量 **0**，不再每颗 `new Mesh` + `material.clone()`
- 帧时间看门狗：连续掉帧自动降一档画质并提示，只降一次
- 金币从"每枚一个 Mesh"改为 **InstancedMesh**：2539 枚 = 各 1 次绘制

**内容**

- 金币 **1269 → 2539**，路线成串；拾取有冲击波、火花、`+N` 浮字、连击音高
- **连击**：1.2 秒窗口，满 10 触发冲刺 + 2.6 秒无敌
- **稀有金币 69 枚**：紫色、1.65 倍体积、60 分，**磁吸半径 12 m**（普通 8.5 m）
- **金币磁吸**：进入半径自动飞来并缩小，身后拖光尾
- 据点：头顶标记（只显示最近 3 个）、进度点 `3/8`、清点结算卡（用时/击杀/金币）+ 保底稀有金币，按 **T** 直达下一处

**适配与交互**

- **Tab** 一键收起顶部信息（H5 也有「信息」按钮），**L** 切中英
- 默认进游戏即**全屏**（真实手势触发），安卓尝试锁横屏
- 竖屏适配：HUD 紧凑化、控制环钳到 420px 防止被裁、旋转提示下移

**本地排行榜**

- `localStorage` 存最高 5 次：分数 → 用时 → 击杀排序，阵亡与通关都记录，带「清除」按钮
